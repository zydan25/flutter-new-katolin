# تطبيق شبيك | SHOPIK

### برمجة وتطوير: يمن كود للتقنيات الذكية (Yemen Code for Smart Technologies)

تطبيق متكامل لخدمات سداد وباقات الاتصالات اليمنية (يمن موبايل، يو YOU، سبأفون، يمن فورجي 4G، يمن نت ADSL)، المتجر الذكي، شبكات وكروت الوايفاي مع مزامنة لحظية مع خادم API.

---

## هيكل المشروع

```
├── shopik_app/     ← تطبيق فلاتر (Android/iOS) — البوابة الكاملة للخدمات
├── web/            ← تطبيق الويب (React + Vite + Capacitor)
├── _backup/        ← نسخة احتياطية من المشروع القديم (Kotlin + وحدة فلاتر)
└── README.md
```

---

## 📱 تطبيق فلاتر (shopik_app/)

تطبيق فلاتر مستقل يحتوي على خدمات الاتصالات والباقات والاستعلامات والمتجر.

```bash
cd shopik_app
flutter pub get
flutter run                      # للتشغيل على جهاز/مُحاكي
flutter build apk --release --split-per-abi   # لبناء APK
```

## 🌐 تطبيق الويب (web/)

```bash
cd web
npm install
npm run dev        # تشغيل بيئة التطوير (منفذ 3000)
npm run build      # بناء ملفات الإنتاج
```

> ملاحظة: بناء تطبيق أندرويد عبر الويب يتم بـ Capacitor:
> `npm run build && npx cap add android && npx cap sync android`
> ثم فتح مجلد android في Android Studio وأمر **Build APK(s)**.

## 🧩 الخدمات الأساسية

1. **تسديد الاتصالات والباقات اللحظي:** سداد فواتير ورصيد فوري لجميع الشركات اليمنية.
2. **شبكات وكروت الوايفاي:** استعراض الكروت، تأكيد الشراء، عرض أكواد الكروت.
3. **المحفظة الذكية:** مزامنة الرصيد مع الخادم.
4. **الأمان والدخول بالبصمة** (عبر تطبيق الويب).
